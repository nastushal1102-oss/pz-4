## Висновок
На цій практичній роботі я навчилась працювати зі структурою даних стек у C++. Закріпила основні методи: push для додавання, pop для видалення, top для перегляду верхнього елемента та empty для перевірки на порожнечу.
Також застосувала стек для розв'язання практичних задач: підрахувала суму та кількість символів, виконала пошук і фільтрацію випадкових чисел та реалізувала перевірку слова на паліндром.
